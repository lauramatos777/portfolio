# Portfolio Website

A personal front-end portfolio created to present Laura Matos's projects, skills, and approach to building thoughtful digital experiences for international clients and recruiters.

## Live Demo

GitHub Pages: _Coming soon_

## Project Overview

This project is the central place to explore my front-end work. It was designed to showcase selected projects, demonstrate my approach to interface design and responsive development, and give clients and recruiters a clear introduction to my professional profile.

The website combines a project showcase with a concise personal presentation, making it easy to discover my work and get in touch.

## Technologies

- HTML5
- CSS3
- Inline SVG
- Google Fonts

## Features

- Elegant, editorial-inspired Hero section
- Smooth-scroll navigation to projects and contact information
- Project showcase featuring the Essenza Estética & Bem-estar landing page
- External links to the live project and its GitHub repository
- Responsive layout for desktop and mobile screens
- Contact footer with GitHub and email links
- Vintage-inspired visual identity with custom color tokens and typography
- Subtle inline SVG botanical details in the Hero section
- Accessibility considerations, including a skip link, semantic HTML, descriptive labels, and visible focus states

## Design Concept

The interface is inspired by modern editorial portfolios with a minimal, vintage character. A soft palette, elegant display typography, generous white space, and subtle organic details create a refined and welcoming visual experience without distracting from the work itself.

## Getting Started

1. Clone this repository or download the project files.
2. Open the project folder in Visual Studio Code.
3. Install the [Live Server](https://marketplace.visualstudio.com/items?itemName=ritwickdey.LiveServer) extension if it is not already installed.
4. Open `index.html` and select **Go Live** from the VS Code status bar.
5. Open the local address provided by Live Server in your browser.

## Manual Testing

- Verify that the header links smoothly scroll to the Projects section and footer.
- Check that the Essenza Live Demo and GitHub links open in a new tab.
- Confirm that the email link opens the default email application.
- Test the layout at desktop, tablet, and mobile widths.
- Navigate with the keyboard and confirm that visible focus states are shown.
- Use the skip link to ensure it moves focus to the main content.
- Confirm that the Hero SVG decorations remain subtle and do not overlap readable content.
